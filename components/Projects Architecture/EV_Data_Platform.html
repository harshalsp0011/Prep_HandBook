Engineering & Operations

Deep dive into reliability patterns and deployment.

Merge Logic: The src/etl/load.py script uses UPSERT (MERGE) patterns. Re-running the pipeline for the same day updates existing records rather than duplicating them.

Retry Mechanics: API connectors handle rate limits (429 errors) and transient failures with exponential backoff.

Validation: src/etl/data_quality.py enforces schema checks, null-value checks on Station IDs, and range validation for weather metrics.

Testing: The tests/ directory ensures provider schema changes are caught before hitting the warehouse.

Setup: Use .env.example to configure Snowflake credentials and NREL API keys.

Initialization: Execute SQL scripts in sql/ddl/ to build the Star Schema before the first run.
